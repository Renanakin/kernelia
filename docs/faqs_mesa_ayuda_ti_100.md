# Diccionario de 100 FAQs A&Q sobre sistema operativo, dispositivos y errores comunes

Este documento reúne 100 preguntas frecuentes orientadas exclusivamente al uso y resolución de problemas de sistema operativo, periféricos, hardware de usuario final y errores comunes de escritorio. Los temas priorizados coinciden con incidencias recurrentes en soporte de primer nivel, como lentitud del equipo, fallas de arranque, problemas de drivers, errores del sistema operativo, periféricos no reconocidos, audio, pantalla, impresión y conectividad básica del puesto de trabajo [cite:17][cite:18][cite:19].

## Alcance del documento

Este set excluye preguntas de correo, VPN, permisos, cuentas, redes corporativas avanzadas, plataformas colaborativas, inventario o gestión de tickets, salvo cuando ayudan a describir un error operativo del equipo. El foco queda acotado a problemas de sistema operativo, uso del computador, periféricos y fallas frecuentes de escritorio, que suelen concentrar buena parte de los tickets repetitivos de soporte técnico [cite:17][cite:19][cite:24].
