# Back Area (Tools)

Este directorio corresponde al frente Backend operativo (tools del sistema).

## Objetivo
- Ejecutar acciones seguras y auditables en el sistema.
- Exponer capacidades reutilizables para comandos API.

## Flujo de trabajo
1. Implementar tool y validaciones.
2. Proteger acciones sensibles con politica.
3. Mantener auditoria y trazabilidad.
4. Validar con cargo check.

## Definition of Done
- Manejo de errores consistente.
- Seguridad aplicada en operaciones sensibles.
- cargo check en verde.
