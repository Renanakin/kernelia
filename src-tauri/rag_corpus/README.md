# KernelIA RAG Corpus

Corpus tecnico curado para el nucleo RAG de KernelIA.

Reglas:

- cada archivo debe estar en Markdown;
- cada archivo debe iniciar con frontmatter simple entre `---`;
- campos requeridos:
  - `title`
  - `slug`
  - `specialty`
  - `doc_type`
- campos opcionales:
  - `entity_key`
  - `source_kind`
  - `status`

Especialidades iniciales:

- network
- services
- performance
- security
- drivers
- maintenance
- filesystem
- software
