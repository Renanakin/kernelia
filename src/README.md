# Front Area

Este directorio corresponde al frente Frontend (SvelteKit).

## Objetivo
- Construir UI robusta, clara y responsive.
- Integrar con los comandos de Tauri a traves del cliente runtime.

## Flujo de trabajo
1. Desarrollar componentes y vistas.
2. Conectar stores y estado.
3. Integrar llamadas a comandos.
4. Validar con:
   - pnpm check
   - pnpm build

## Dependencias clave
- @sveltejs/kit
- vite
- @tailwindcss/vite
- @tauri-apps/api

## Definition of Done
- Sin errores de check.
- Sin errores de build.
- UI funcional en desktop local Tauri.
